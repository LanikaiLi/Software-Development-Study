# Task Management App — Product Requirements

## Core Features

1. **Create a task** — with title, description, priority, deadline, and status
2. **Update a task's properties** — title, description, priority, deadline, and status
3. **Delete a task**
4. **View all tasks** — organized in four columns by status: Todo, In Progress, Blocked, Done
5. **Click a task** — to view and edit its details
6. **Filter tasks by deadline** — default: current week; user can select a custom date range

## Task Properties

| Property      | Type   | Details                          |
|---------------|--------|----------------------------------|
| Title         | Text   | Required                         |
| Description   | Text   | Optional                         |
| Priority      | Enum   | High / Medium / Low              |
| Status        | Enum   | Todo / In progress / Blocked / Done |
| Deadline      | Date   | —                                |

## Out of Scope

- Authentication
- Drag and drop

---

## API Reference

Base URL: `http://localhost:3000`

All request and response bodies use JSON. Task `_id` values are MongoDB ObjectIds.

### Task object

| Field         | Type     | Description                                      |
|---------------|----------|--------------------------------------------------|
| `_id`         | ObjectId | Auto-generated by MongoDB                        |
| `title`       | string   | Task title                                       |
| `description` | string   | Optional task description                        |
| `priority`    | string   | `High` / `Medium` / `Low`                        |
| `status`      | string   | `Todo` / `In progress` / `Blocked` / `Done`      |
| `deadline`    | string   | Date as `YYYY-MM-DD`                             |
| `created_at`  | Date     | Set automatically on create                      |

---

### 1. Create a task

Supports: **Create a task**

```
POST /tasks
```

**Request body**

```json
{
  "title": "Write report",
  "description": "Weekly status update",
  "priority": "High",
  "status": "Todo",
  "deadline": "2026-07-18"
}
```

**Response** `201 Created`

```json
{
  "message": "Task created",
  "task": {
    "_id": "...",
    "title": "Write report",
    "description": "Weekly status update",
    "priority": "High",
    "status": "Todo",
    "deadline": "2026-07-18",
    "created_at": "..."
  }
}
```

---

### 2. Update a task

Supports: **Update a task's properties**

```
PATCH /tasks/:id
```

Sends only the fields to change. Other fields are left unchanged.

**Request body** (example)

```json
{
  "status": "In progress",
  "priority": "Medium"
}
```

**Response** `200 OK`

```json
{
  "message": "Task updated",
  "task": { /* full updated task */ }
}
```

**Errors**

| Status | Body                              |
|--------|-----------------------------------|
| `404`  | `{ "error": "Task not found" }`   |

---

### 3. Delete a task

Supports: **Delete a task**

```
DELETE /tasks/:id
```

**Response** `200 OK`

```json
{
  "message": "Task deleted",
  "task": { /* delete result */ }
}
```

**Errors**

| Status | Body                              |
|--------|-----------------------------------|
| `404`  | `{ "error": "Task not found" }`   |

---

### 4. List / filter tasks

Supports: **View all tasks**, **Filter tasks by deadline**

```
GET /tasks
GET /tasks?range=this_week
GET /tasks?range=last_week
GET /tasks?range=next_week
GET /tasks?range=all
```

**Query parameters**

| Param   | Values                                         | Default      | Description                                      |
|---------|------------------------------------------------|--------------|--------------------------------------------------|
| `range` | `this_week` / `last_week` / `next_week` / `all` | `this_week` | Filter by deadline week; `all` returns every task |

Weeks run Monday–Sunday. Filtering compares `deadline` as `YYYY-MM-DD` strings.

**Response** `200 OK`

```json
{
  "tasks": [ /* array of task objects */ ]
}
```

---

### 5. Get a task by ID

Supports: **Click a task to view and edit its details**

```
GET /tasks/:id
```

**Response** `200 OK`

```json
{
  "task": { /* single task object */ }
}
```

**Errors**

| Status | Body                              |
|--------|-----------------------------------|
| `404`  | `{ "error": "Task not found" }`   |
